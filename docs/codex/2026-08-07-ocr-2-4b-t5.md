The finalize action does not enforce the required positive page-count invariant, allowing zero-page PDFs to be reported as successfully finalized.

  When PDFium accepts a structurally valid zero-page PDF, this check only rejects counts above the maximum, so `finalizePdfSource` returns `{ pageCount: 0 }` and leaves the object stored.
