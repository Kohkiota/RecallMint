The collapse behavior visually hides interactive controls without removing them from keyboard or assistive-technology navigation, introducing an accessibility/UX bug.

Review comment:

- [P2] Remove collapsed chrome controls from the tab order — /workspaces/RecallMint/app/(app)/app/exams/[id]/_components/exam-detail-view.tsx:233-235
  When `chromeCollapsed` is true, this only clips the chrome to a zero-height grid row; the `ColumnVisibilityToggle` and view-toggle buttons inside remain focusable and exposed to assistive tech. After scrolling far enough to collapse the chrome, keyboard users can tab to invisible controls and potentially activate them, so the collapsed state should also apply `inert`/`aria-hidden` or otherwise disable/unmount these controls.
