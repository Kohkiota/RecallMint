- [P1] Make the derivation guard atomic with collection — /workspaces/RecallMint/scripts/gc-image-assets.ts:651-654
  When a crop transaction inserts an `asset_derivations` row after `fetchDerivedSourceAssetIds()` returns but before `deleteObject()`/`deleteSourceAssetRow()`, this loop still deletes the R2 source and then cascades away the newly committed provenance row. `crop-and-store.ts` performs external processing before its insert, so the acknowledged race can span this fresh read; merely shortening the window does not preserve the RETAIN invariant.
