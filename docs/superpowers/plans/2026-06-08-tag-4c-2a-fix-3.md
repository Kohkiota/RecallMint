**制約:**

- `TagComboboxItem` 型に `select_type?: 'single' | 'multi'` を**optional 追加** (既存フィールド `id`, `name`, `color?` 維持)
- `ClientTagCategory[]` (現 stage1 で popover が渡す) は structural compat (`select_type` を持つ)、 `ClientTagOption[]` も compat (`select_type` 未定義 → undefined)、 popover 側 props 0 改修
- row JSX の button 内、 **color pill の前** (= button の最初の child) に conditional icon render を挿入:
  ```tsx
  {kind === 'category' && item.select_type === 'single' && (
    <CircleDot className="h-3.5 w-3.5 text-slate-400" aria-hidden="true" />
  )}
  {kind === 'category' && item.select_type === 'multi' && (
    <CheckSquare className="h-3.5 w-3.5 text-slate-400" aria-hidden="true" />
  )}
  ```
- icon size `h-3.5 w-3.5` (= 14px、 kebab `h-4 w-4` より小)、 色 `text-slate-400` (淡め、 名前を主)
- `aria-hidden="true"` で screen reader は icon を読まない (情報は select_type で別経路、 button text で読まれる)
- import 追加: `import { CheckSquare, CircleDot, ... } from 'lucide-react'` (既存 import に merge、 `CircleDot` は Tag-4c-2a-fix-2 で導入済の可能性あり要確認)
- option 行 (`kind === 'option'` または `item.select_type === undefined`) は icon を**出さない** (defensive、 spec §設計判断 5)
- `Check` icon (kind='option' で selected 時) の render 条件は無改修 (Tag-4c-2a-fix Task 1 / Task 2 由来)
- kebab・color pill・existing row layout 一切無改修

**完了条件:**

- `TagComboboxItem` 型に `select_type?: 'single' | 'multi'` が optional で含まれる
- test:
  - kind='category' + select_type='single' → 行頭に `CircleDot` SVG が出る (DOM query `svg.lucide-circle-dot` で 1 件以上)
  - kind='category' + select_type='multi' → 行頭に `CheckSquare` SVG が出る (DOM query `svg.lucide-check-square`)
  - kind='category' + select_type=undefined → icon 出ない (defensive)
  - kind='option' + 任意 selected 状態 → icon 出ない (Fix-4 目的: 視覚区別)
  - 既存 kind='option' selected Check icon は引き続き表示 (regression)
  - 既存 kebab / color pill / row click 挙動全て regression なし
- `pnpm test` 全件緑、 `pnpm build` 緑、 tsc strict 緑 (型拡張で既存 `ClientTagOption[]` / `ClientTagCategory[]` 呼出が壊れていないこと)
