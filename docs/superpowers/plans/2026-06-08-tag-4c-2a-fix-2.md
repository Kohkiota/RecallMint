### Task 3: 編集 stage rename input 全選択 focus (Fix-3)

**Files:**
- Modify: `app/(app)/app/exams/[id]/_components/card-tag-edit-fields.tsx`
- Modify: `app/(app)/app/exams/[id]/_components/card-tag-edit-fields.test.tsx`
- Modify: `app/(app)/app/exams/[id]/_components/card-tag-add-popover.tsx` (editCategory / editOption stage の `<CardTagEditFields key={...} />` 付与)
- Modify: `app/(app)/app/exams/[id]/_components/card-tag-edit-popover.tsx` (editOption stage の `<CardTagEditFields key={...} />` 付与)
- Modify: `app/(app)/app/exams/[id]/_components/card-tag-add-popover.test.tsx`
- Modify: `app/(app)/app/exams/[id]/_components/card-tag-edit-popover.test.tsx`

**目的:** kebab → 編集 stage 遷移時に rename input が focus 済 + テキスト全選択済にする。 同 stage 内で別 target に kebab した場合も再発火する (`key` 経由で再 mount)。

**制約:**

- `card-tag-edit-fields.tsx` に `useEffect` を追加:
  ```tsx
  React.useEffect(() => {
    inputRef.current?.focus()
    inputRef.current?.select()
  }, [])
  ```
  - mount 時のみ実行 (deps `[]`)
  - JSDoc に 1 行追記「Tag-4c-2a-fix-2 Fix-3: mount 時 全選択 focus、 stage 遷移 / target 切替時の再発火は親側 `key={editTargetId}` で担保」
- `inputRef` は既存 (Tag-4c-1 で `<Input ref={inputRef}>` として存在、 確認)
- popover 3 箇所で `<CardTagEditFields key={editTargetId ?? 'none'} ... />` を付与:
  - `card-tag-add-popover.tsx` editCategory stage: `key={editTargetId ?? 'none'}` (editTargetId は category id)
  - `card-tag-add-popover.tsx` editOption stage: `key={editTargetId ?? 'none'}` (editTargetId は option id)
  - `card-tag-edit-popover.tsx` editOption stage: `key={editTargetId ?? 'none'}` (editTargetId は option id)
- `editTargetId` の型は `string | null` のため fallback `'none'` で React warning を避ける (null key で warning が出る挙動を防ぐ)
- `useEffect` 内で `setFocused(true)` 相当の state 同期は**しない** (`focus` event handler で既存 `setFocused(true)` が発火する、 既存挙動を流用)
- 既存の `onFocus={() => setFocused(true)}` / `onBlur={handleBlur}` / value 同期 logic は無改修
- delete button 等の他 element には focus が当たらない (input への明示的 `.focus()` 呼出のみ)
- Radix Popover の `onOpenAutoFocus` は**触らない** (本 sprint で必要ない)

**完了条件:**

- `card-tag-edit-fields.test.tsx`:
  - 新規 test「mount 時 inputRef.focus() + inputRef.select() が呼ばれる」 緑
  - assert: `expect(document.activeElement).toBe(inputElement)` + `expect(inputElement.selectionStart).toBe(0)` + `expect(inputElement.selectionEnd).toBe(inputElement.value.length)`
  - 既存 test の regression なし (rename / color / delete / Esc / inline error 全て不変)
- `card-tag-add-popover.test.tsx`:
  - kebab click (category) → editCategory stage → rename input が focus + 全選択
  - kebab click (option) → editOption stage → rename input が focus + 全選択
  - editOption stage 中に**別 option の kebab を click** (editTargetId 変化) → 再 mount → 全選択 focus 再発火 (assert via `selectionStart=0` + `selectionEnd=value.length` after second kebab)
- `card-tag-edit-popover.test.tsx`:
  - バッジ click 経路の editOption stage 入った瞬間 rename input が focus + 全選択
  - 別 option の kebab → editTargetId 変化 → 全選択 focus 再発火
