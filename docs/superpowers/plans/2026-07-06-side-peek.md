# side peek(統合 1 本)Implementation Plan(ドラフト)

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development(task 単位 fresh subagent + task 間 review)。Steps は checkbox 追跡。
> **状態:** plan ドラフト(未確定)。codex-plan-review cross-check → OT 承認で確定。実装は承認後。

**Goal:** テーブル行から単票を右スライド overlay(non-modal)で開き、click-to-edit プリミティブで単票全項目をその場編集する。

**Architecture:** 新規 presentational `ExamCardSidePeek`(radix Dialog `modal={false}` + Portal + `fixed right-0 z-[45]`)に既存プリミティブ(`InlineTextField` / `InlineOptionList` / `CardTagsSection`)を直載せ。トリガーは title セル内 hover ボタン(InlineTextField の兄弟絶対配置・startEdit 非経由)。状態 owner は `ExamCardTable`(`activeCardId`)、表示は join 済 `data` から live 参照(全件保持のためフィルタ非表示でも生存、削除時のみ prune)。モバイルは同パネル全幅(案 b・route 新設なし)。

**Tech Stack:** Next.js App Router / TS strict / TanStack Table / Dexie(useLiveQuery)/ radix-ui@1.4.3 Dialog / tw-animate-css / Vitest + RTL。

**Spec(唯一の起点):** `docs/superpowers/specs/2026-07-06-side-peek-design.md`

### Task 2: title セル hover ボタン(トリガー)+ meta 拡張

**目的:** title 列 cell 内に peek button を新設し、click-to-edit(startEdit)と衝突しない peek 起動経路を作る(spec §3.3)。

**Files:** Modify `app/(app)/app/exams/[id]/_components/exam-card-table-columns.tsx`(`ExamCardTableMeta` 拡張 + title cell 改修)+ `exam-card-table-columns.test.tsx` 追記。**column-toggle は触らない**(専用列を作らないため)。

**Interfaces(Produces、T3 が実装・消費):**

```ts
export type ExamCardTableMeta = {
  /* 既存 5 フィールド不変 */
  activeCardId: string | null          // trigger の開状態表示用
  openCard: (cardId: string) => void   // 同一 id 再 click = close(toggle 実装は T3)
}
```

- title cell を wrapper 化(現状は `<InlineTextField/>` 直置き):

```tsx
cell: ({ row, table }) => {
  const card = row.original.card
  const meta = table.options.meta as ExamCardTableMeta | undefined
  return (
    <div className="relative w-full group/peek">
      <InlineTextField cardId={card.id} field="title" initialValue={card.title} ariaLabel="タイトル 編集" />
      {meta && (
        <button
          type="button"
          aria-label="カードを開く"
          aria-pressed={meta.activeCardId === card.id}
          onClick={() => meta.openCard(card.id)}
          className={cn(
            'absolute right-0.5 top-0.5 z-[1] inline-flex size-7 items-center justify-center rounded bg-background shadow-sm text-muted-foreground hover:text-foreground',
            'opacity-100 md:opacity-0 md:group-hover/peek:opacity-100 md:focus-visible:opacity-100',
            'group-has-[input]/peek:opacity-0 group-has-[input]/peek:pointer-events-none',
            'aria-pressed:text-foreground',
          )}
        >
          <PanelRightOpen className="size-4" aria-hidden="true" />
        </button>
      )}
    </div>
  )
}
```

- lucide icon は `PanelRightOpen`(side-peek を想起させる。import 追加)。`meta` 不在で button 非描画(既存 tags 列 `:181-182` パターン)。`cn` は既存 import(なければ `@/lib/utils` から追加)。
- **wrapper に `w-full`**(InlineTextField の `w-full` display box を親幅いっぱいに保ち、td 高さ計算を不変にする — Codex 指摘)。button は `size-7`(28px)tap target(title セル密度と 44px 推奨の折衷。狭さは受容 = Codex Minor)。位置は `top-0.5 right-0.5`(title 折返し時も右上固定でテキストと重なりにくい。center 固定は複数行時に本文へ被るため不採用)。

**制約(spec §3.3):**
- 行 `<tr>`・wrapper・td に onClick を置かない。**stopPropagation を足さない**(button は display div の兄弟でバブリング経路が別 = 構造的に非衝突)。**この非衝突は「親側に click handler を置かない前提」で成立する**(将来 wrapper/td/tr に click を足すなら再検討 — Codex 指摘の明文化)。行全体ハイライトを足さない(YAGNI)。
- 表示制御・編集中非表示・mobile 常時表示は **CSS のみ**(has- variant / opacity + md: breakpoint)。JS viewport 判定・props 追加をしない。
- **`group-has-[input]/peek` で十分な根拠**: title 列は `multiline` prop なし = editing 時 `<Input>`(input タグ)に置換される(`inline-text-field.tsx` の Input/Textarea 分岐)。トリガーは title セル**のみ**に置くため textarea 分岐は発生しない。よって `group-has-[textarea]` は不要(YAGNI)。**受容リスク**: InlineTextField の内部 DOM(input タグ使用)に CSS が依存する — 将来 display↔edit 構造が変わると編集中非表示が壊れる(props 非追加方針とのトレードオフ、Codex 指摘)。
- title 列の `accessorFn` / `sortingFn` / `filterFn` / `size` は不変(cell の中身だけ wrapper 化)。

**完了条件:**
- columns test 追記: ① title cell に「カードを開く」button 存在 ② button click で `meta.openCard(card.id)` 呼出 ③ meta 不在で button 非描画・crash しない ④ `aria-pressed` が `meta.activeCardId` と連動 ⑤ button click が InlineTextField の編集を起動しない(startEdit 非経由 — RTL で button click 後に title の Input が現れないことを確認)⑥ 編集中非表示 class(`group-has-[input]/peek:opacity-0` + `pointer-events-none`)と mobile 常時表示 class(`opacity-100 md:opacity-0`)と wrapper `w-full` が付与されている ⑦ title 列の accessorFn/size 等が不変(既存 columns test green 維持)⑧ title 列 hidden(columnVisibility)時に既存 render が crash しない(到達不能は許容だが非表示設定自体の回帰を防ぐ — Codex 指摘)。
- typecheck 0。canonical + Codex 両 Critical/Important 0 + `[reviewed]`。
