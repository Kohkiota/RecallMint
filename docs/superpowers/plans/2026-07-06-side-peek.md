# side peek(統合 1 本)Implementation Plan(ドラフト)

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development(task 単位 fresh subagent + task 間 review)。Steps は checkbox 追跡。
> **状態:** plan ドラフト(未確定)。codex-plan-review cross-check → OT 承認で確定。実装は承認後。

**Goal:** テーブル行から単票を右スライド overlay(non-modal)で開き、click-to-edit プリミティブで単票全項目をその場編集する。

**Architecture:** 新規 presentational `ExamCardSidePeek`(radix Dialog `modal={false}` + Portal + `fixed right-0 z-[45]`)に既存プリミティブ(`InlineTextField` / `InlineOptionList` / `CardTagsSection`)を直載せ。トリガーは非 hideable な専用 `open` 列。状態 owner は `ExamCardTable`(`activeCardId`)、表示は join 済 `data` から live 参照(全件保持のためフィルタ非表示でも生存、削除時のみ prune)。モバイルは同パネル全幅(案 b・route 新設なし)。

**Tech Stack:** Next.js App Router / TS strict / TanStack Table / Dexie(useLiveQuery)/ radix-ui@1.4.3 Dialog / tw-animate-css / Vitest + RTL。

**Spec(唯一の起点):** `docs/superpowers/specs/2026-07-06-side-peek-design.md`

## Global Constraints

- 起点は spec のみ。spec 凍結。仕様変更が要るなら停止して OT 相談。
- 各 task 完了条件 = ① 該当 unit/component test green ② canonical + Codex 両 Critical/Important 0 ③ `[reviewed]`。
- **書込は既存共通経路のみ**(`runOptimisticUpdate` / `useCardTagToggle`)。新 helper・server action・型変換マッパ・同期コードを足さない。
- **プリミティブは fork せずそのまま載せる**(`InlineOptionList` は `CardOption[]` = `ClientCard.options` 同 shape でマッパ不要)。
- **追加 dep ゼロ / 追加 fetch ゼロ**(手元 `data` row 流用)。`Dialog.Overlay`(backdrop)を描画しない。scroll lock・focus trap を足さない(non-modal)。
- **閉じ方 = × + Esc のみ**。`onInteractOutside` は `preventDefault`(外クリックで閉じない)。
- **prune = card が `data` から消えた時のみ**。フィルタ・ソートの可視集合離脱では閉じない。それ以外の防御コード禁止。
- z-index: パネル `z-[45]` 固定(ActionBar z-40 より上・popover/dialog z-50 より下)。既存 z 値のリナンバー禁止。
- パネル幅: `w-full md:w-[480px]` 固定。リサイズ・幅永続・JS viewport 判定を導入しない。
- カード削除/追加ボタン・judged 確認ビュー・行クリック trigger・新 route は OUT(spec §4)。
- rowSelection / examViewPrefs / sticky / pinning / virtualizer / InlineCardList / exam-detail-view 既存挙動不変。
- Test: Vitest + RTL。`git commit --no-verify` / `-n` 全面禁止。

### Task 1: `ExamCardSidePeek`(パネル shell + 単票 content)

**目的:** radix Dialog non-modal の右スライドパネルに単票全項目の click-to-edit を載せた presentational component を新設する(spec §3.2/3.5、状態は持たない)。

**Files:** Create `app/(app)/app/exams/[id]/_components/exam-card-side-peek.tsx` + `.test.tsx`。

**Interfaces(Produces):**

```ts
export type ExamCardSidePeekProps = {
  row: ExamCardRow | null            // null = closed(ExamCardRow from './exam-card-table-columns')
  cardTags: ClientCardTag[]          // 当該 card の raw card_tags(CardTagsSection へそのまま)
  categories: ClientTagCategory[]
  options: ClientTagOption[]
  userId: string
  onClose: () => void
}
export function ExamCardSidePeek(props: ExamCardSidePeekProps): React.JSX.Element | null
```

**制約(spec §3.1-5/3.2/3.5):**
- radix `Dialog`(`radix-ui` 統合パッケージから import)`open={row !== null}` `modal={false}`。`Dialog.Portal` + `Dialog.Content` のみ(`Dialog.Overlay` なし)。`onEscapeKeyDown` → `onClose`、`onInteractOutside` → `event.preventDefault()`。
- Content class: `fixed inset-y-0 right-0 z-[45] w-full md:w-[480px] bg-background border-l shadow-lg data-open:animate-in data-open:slide-in-from-right data-closed:animate-out data-closed:slide-out-to-right duration-200 motion-reduce:transition-none` + 内部 = ヘッダー(`Dialog.Close` の × button、`aria-label="閉じる"`)+ `overflow-y-auto` 本文。`Dialog.Title` は card.title(空なら「カード」)で a11y 充足。
- 本文 = `InlineCardList` 1 枚分(`inline-card-list.tsx:280-373`)を雛形に、content 子ツリーを `key={row.card.id}` で remount: `InlineTextField` ×5(`sort_key`/`title`/`question_text`/`explanation_text`/`memo`、`initialValue` は `row.card` の snake_case 値、question/explanation/memo は `multiline`)+ `InlineOptionList({cardId, options: row.card.options})` + `CardTagsSection({cardId, userId, categories, options, cardTags})`。**`DeleteCardButton` を置かない**。`autoEditOnMount` 系は渡さない。

**完了条件(test green + Critical/Important 0 + `[reviewed]`):**
- `.test.tsx`: ① row 有りで全フィールド表示(sort_key/title/問題文/選択肢 text・正解 checkbox/タグ badge/解説/メモの値)② row=null で非描画 ③ × click で `onClose` 1 回 ④ Esc keydown で `onClose` ⑤ パネル外要素への pointer interaction で `onClose` が呼ばれない ⑥ DeleteCardButton(「削除」button)が存在しない ⑦ row 差し替え(card.id 変化)で編集中 state がリセットされる(remount)。
- typecheck 0。smoke は sprint 末 gate。

### Task 3: `ExamCardTable` 統合(activeCardId + prune + peek render)

**目的:** activeCardId 状態と prune を table に配線し、peek を live data 接続で描画する(spec §3.4/3.6/3.8)。

**Files:** Modify `app/(app)/app/exams/[id]/_components/exam-card-table.tsx` + `exam-card-table.test.tsx` 追記。

**Interfaces(Consumes):** `ExamCardSidePeek`(T1)/ `meta.openCard`(T2)/ 既存 `data: ExamCardRow[]` `liveData.cardTags` `rowSelection`。

**制約(spec §3.4/3.6/3.8):**
- `const [activeCardId, setActiveCardId] = useState<string | null>(null)`(`rowSelection` と同期しない・examViewPrefs に書かない)。
- `openCard = useCallback((id) => setActiveCardId(prev => prev === id ? null : id), [])` を meta object に追加(meta の useMemo deps 更新)。
- `activeRow = activeCardId ? data.find(r => r.card.id === activeCardId) ?? null : null`。`activeCardTags = liveData?.cardTags.filter(ct => ct.card_id === activeCardId) ?? []`(useMemo、deps = liveData/activeCardId)。
- prune effect: `activeCardId !== null && activeRow === null` で `setActiveCardId(null)`。**可視集合(getFilteredRowModel)を参照しない**(rowSelection prune :458-478 と目的が異なるため流用しない)。
- render: ルート div 末尾(ActionBar ブロックの後)に `<ExamCardSidePeek row={activeRow} cardTags={activeCardTags} categories={...} options={...} userId={userId} onClose={() => setActiveCardId(null)} />`。スクロールコンテナ(`:618`)内に置かない。
- 既存 render 構造(condition-bar / table / ActionBar / FAB)のレイアウト・class を変更しない。

**完了条件:**
- `exam-card-table.test.tsx` 追記 green: ① open 列 click で peek に該当 card 内容表示 ② 同一行 再 click で close(toggle)③ 別行 click で card 切替 ④ × で close ⑤ data から該当 card 消滅(削除相当の rerender)で自動 close ⑥ columnFilters で該当行が非表示になっても peek が開いたまま ⑦ rowSelection 操作が activeCardId に影響しない(直交)⑧ data の該当 card 更新が peek 表示に反映(live 追従)。
- typecheck 0。canonical + Codex 両 Critical/Important 0 + `[reviewed]`。
- 視覚系(slide アニメ・z 重なり・ActionBar/FAB 共存・mobile 全幅)は sprint 末 stg smoke(per-task ブロッカーにしない)。
